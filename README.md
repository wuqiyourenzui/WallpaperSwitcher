# 壁纸切换 (WallpaperSwitcher)

一款轻量级 Android 壁纸自动切换应用，支持分组管理、多种切换模式和图片适配方式。

## 功能特性

### 🔄 切换方式
- **定时切换**：支持最低 10 秒的定时切换间隔
- **双击切换**：双击屏幕即可切换（动态壁纸模式）
- **解锁切换**：每次解锁屏幕自动切换壁纸（动态壁纸模式走引擎；静态壁纸模式直接静态切换）
- **手动切换**：一键立即切换
- **点击图片即设置**：在分组里点一下图片/视频，直接进入系统动态壁纸界面完成设置（每次都显示系统确认页）

### 📁 壁纸来源
- 添加单张图片
- 批量选择多张图片
- 添加整个文件夹（自动扫描图片）
- 支持 JPG / PNG / WebP / BMP / GIF / MP4 格式

### 📂 分组管理
- 自定义壁纸分组（图片、视频、GIF 可混合存放）
- 全局设置切换间隔、切换模式、缩放模式
- 分组可独立启用/禁用
- 分组可重命名（分组详情页右上角 ✎）
- 支持批量选择和删除

### 🎲 切换模式
- **随机**：完全随机选取
- **顺序**：按添加顺序依次切换
- **洗牌**：随机不重复，全部轮完后重新洗牌

### 🖼️ 图片适配
- **填充**：裁剪多余部分，填满屏幕，保持比例
- **适应**：完整显示图片，可能有黑边
- **拉伸**：强制拉伸填满屏幕
- **自动旋转适配**：填充/拉伸时，方向与屏幕不符的图片/视频/GIF 自动旋转 90°，可选择**顺时针**或**逆时针**

### 🔊 视频声音（可选，默认关闭）
- 设置 →「视频壁纸播放声音」打开后，视频壁纸会播放**自带的声音**，跟随系统媒体音量
- 只在**桌面可见**时出声：进入应用、熄屏、锁屏、系统壁纸预览界面都自动静音，恢复可见时接着放（不快进补播）
- 音画按每个播放循环重新对齐：循环点不再重建解码器和音轨，**循环之间不中断也没有咔哒声**，
  循环多久都不会出现越来越不同步；没有音轨的视频只记一条日志，不会报错

### 📱 桌面与锁屏分开设置（参考 Paperize 双屏思路）
- 每个分组可选 **应用位置**：桌面 / 锁屏 / 桌面和锁屏
- 桌面和锁屏**各自独立轮换**：桌面从"包含桌面"的分组取图，锁屏从"包含锁屏"的分组取图，
  各有一套顺序/洗牌游标；例如「日常」分组只设桌面、「风景」分组只设锁屏，两块屏就会各换各的
- **锁屏定时切换独立于桌面**（设置 →「锁屏切换（独立于桌面）」）：
  独立开关 + 独立间隔，可以和桌面完全不一样（例如桌面 1 小时、锁屏 30 秒）。
  桌面的定时/双击/解锁切换**不会**再动锁屏，锁屏只按自己的定时规则轮换。
- **手动设置优先于定时（按屏生效）**：手动设完之后，那块屏的定时从"现在"重新计时，所以刚设的图至少完整显示一个间隔；
  桌面侧还会额外让路 15 秒（保证系统动态壁纸确认页里看到的选的就是你点的那张）。
  锁屏定时不会被手动设置阻塞——早期版本共用一个 60 秒保护期，连续手动设锁屏图时锁屏定时会一直轮不上，现已修复。
- **动态壁纸不会霸占锁屏**：系统动态壁纸界面选「主屏幕和锁定屏幕」后，只要你有"应用位置=锁屏"的分组，
  应用会在 3 秒内把锁屏恢复成该分组的壁纸，分组设置优先于系统对话框。
- **任何分组都能设为动态壁纸**：点分组里的图片都会进入系统动态壁纸界面（桌面/锁屏/两者分组都一样）。
  设置完成后显示哪张图由分组位置决定——桌面显示"含桌面"分组的图、锁屏显示"含锁屏"分组的图；
  锁屏分组/两者分组会自动把你点的这张放到锁屏，桌面继续轮换桌面分组的图。
- **锁屏只接受静态图片**：锁屏分组里的**视频/GIF 会被自动跳过**（不会把首帧冻在锁屏上）。
  如果某个锁屏分组里只有视频/GIF，锁屏就保持原样不动；手动对视频/GIF 点「设为壁纸」时也会提示"锁屏不支持视频/GIF，已自动跳过"。
- **菜单更简洁**：每个媒体右下角 ⋮ 只有 **设为壁纸 / 删除**；设为动态壁纸统一走"点一下图片"。
- **两块屏缓存互不串图**：动态壁纸引擎只渲染"含桌面"分组的图片；即使旧版本留下的游标指向锁屏图片，
  引擎发现后也会自动改回桌面分组的图片。
- **分组位置优先于系统对话框**：系统动态壁纸界面选完选项后，应用会在 3 秒内按分组位置校正两个槽位：
  | 分组位置 | 系统界面选什么 | 结果 |
  |---|---|---|
  | 桌面 | 主屏幕（推荐） | 只有桌面变，锁屏保持原样 ✅ |
  | 桌面 | 主屏幕和锁定屏幕 | 锁屏自动恢复成原来的锁屏壁纸（不会被动态壁纸占掉） |
  | 锁屏 | 点「设置壁纸」确认即可（该界面没有"锁屏"选项，提示条会写明） | 你点的这张会写到锁屏，桌面不动 |
  | 两者 | 任选（含只选主屏幕） | 锁屏会自动同步成同一张，两边都生效 |

### ⚡ 低功耗
- 使用 Kotlin 协程调度，不依赖 AlarmManager
- 前台服务占用内存极小
- 支持开机自启动
- **锁屏暂停 + 解锁补切**：锁屏期间不做任何切换/解码，但锁屏时长照常计入；解锁时若已到期立即补切一次，无需重新等满一个间隔
- **应用在前台时桌面定时完全不切**：打开应用后桌面壁纸看不见，定时**一次都不切**（不做解码/编码）；
  退出应用立刻唤醒定时循环并**立刻补切一张**（离开应用时那一刻就换好），随后从这一刻起按正常间隔轮换。
  锁屏定时独立，不受此影响。
- **补切安全**：补切前等动态壁纸渲染表面就绪（避免解锁后壁纸空白），并与「解锁切换」协调避免连切两次
- **事件驱动，不做空转轮询**：无锁屏分组时不再每 15 秒醒一次，改为在媒体/分组变更、预览引擎退出时被唤醒
- **同一张图不重复写**：桌面/锁屏都记住"这块屏上现在是哪张"，30 分钟内命中就跳过解码与写入（单图分组不再每个间隔重写一次）
- **崩溃不拖垮进程**：所有长生命周期协程都带异常处理器，后台一处抛错只记一条日志，不会再把壁纸引擎和前台服务一起带走

## 架构

```
├── data/           # Room 数据库 (Entity, DAO, Database)
├── engine/         # 壁纸引擎核心逻辑（位图加载、静态壁纸应用）
├── service/        # 前台服务
├── receiver/       # 广播接收器 (开机、解锁)
├── wallpaper/      # 动态壁纸服务
├── viewmodel/      # ViewModel
└── ui/
    ├── theme/      # Material 3 主题
    └── screens/    # Compose 界面
```

## 技术栈

- **语言**：Kotlin
- **UI**：Jetpack Compose + Material 3
- **数据库**：Room
- **图片加载**：Coil
- **异步**：Kotlin Coroutines + Flow
- **架构**：MVVM

## 构建

1. 用 Android Studio 打开项目根目录
2. 同步 Gradle
3. 连接设备或启动模拟器
4. Run → 运行

## 使用指南

### 静态壁纸模式（后台服务）
1. 打开应用 → 新建分组
2. 进入分组 → 添加图片或视频
3. 设置切换间隔和模式
4. 进入图片 → 「设为壁纸」应用静态壁纸
5. 回到首页 → 开启自动切换，后台会定时切换静态壁纸

### 动态壁纸模式（支持双击切换、视频/GIF 动画）
1. 系统设置 → 壁纸 → 动态壁纸
2. 选择「动态壁纸切换」
3. 设置为壁纸
4. 双击屏幕即可切换

### 添加视频后显示黑屏？（老版本数据自愈）
非小米机型通过系统文件选择器添加的视频，早期版本会因为没有扩展名而被识别成图片，
显示为黑屏。当前版本按 MIME 类型识别（video/*、image/gif），并且动态壁纸引擎在
遇到这种旧数据时会自动修正数据库里的类型并重新播放，无需重新添加。
